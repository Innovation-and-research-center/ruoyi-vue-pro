# 义乌市智慧自然资源综合管理信息系统 OA 子系统操作手册

## 1. 文档说明

### 1.1 编写目的

本手册用于指导系统用户完成 OA 子系统中的流程发起、任务办理、公文流转、专项业务登记、会议室预约和值班管理等操作，同时为系统管理员提供基础配置说明。

### 1.2 适用范围

本手册适用于以下用户：

- 普通工作人员：发起流程、查询本人流程、办理待办任务。
- 部门负责人及分管领导：审批、退回、转办相关任务。
- 办公室及业务科室人员：办理收文、发文、会议报告单等业务。
- 法规业务人员：办理行政复议、行政诉讼案件。
- 系统管理员：维护用户、角色、菜单、字典和流程配置。

### 1.3 权限说明

系统采用基于角色的菜单和按钮权限控制。

- 不同用户登录后看到的菜单可能不同。
- 新增、编辑、删除、导入、导出、审批等按钮是否显示，以账号权限为准。
- 手册中提到的菜单未显示时，请联系系统管理员检查角色和菜单授权。
- 用户只能查看权限范围内的数据，部分业务还会受到部门数据权限限制。

### 1.4 操作环境

建议使用最新版 Microsoft Edge、Google Chrome 等现代浏览器访问系统。

## 2. 登录与退出

### 2.1 登录系统

1. 使用浏览器打开系统地址。
2. 输入租户、用户名和密码。租户输入框是否显示，以系统配置为准。
3. 根据页面提示完成验证码验证。
4. 单击“登录”进入系统。

若系统启用了统一身份认证，也可以通过单点登录入口进入系统。

### 2.2 登录失败处理

- 提示用户名或密码错误：确认大小写及账号状态后重新输入。
- 提示验证码错误：刷新验证码后重新验证。
- 提示账号无权限：联系系统管理员检查账号、角色和部门配置。
- 单点登录异常：记录异常页面信息并联系系统管理员。

### 2.3 退出系统

1. 单击页面右上角的用户头像或用户名。
2. 选择“退出登录”。
3. 确认后返回登录页面。

## 3. 系统界面

### 3.1 页面组成

系统主要由以下区域组成：

- 菜单栏：显示当前账号可访问的业务菜单。
- 顶部工具栏：提供页面搜索、消息、个人中心和退出等入口。
- 页签栏：显示已打开的业务页面，可切换或关闭页签。
- 内容区：显示查询条件、业务列表、表单和流程详情。

### 3.2 通用查询

多数列表页面支持以下操作：

1. 输入一个或多个查询条件。
2. 单击“搜索”或“查询”刷新列表。
3. 单击“重置”清除查询条件。
4. 部分页面可以单击“展开”显示更多条件。
5. 单击表头可按支持的字段排序。
6. 拖动表头边界可以调整部分列表列宽。
7. 通过分页组件切换页码或每页显示数量。

### 3.3 通用新增和编辑

1. 在列表页面单击“新增”。
2. 填写带星号的必填项。
3. 单击“确定”“保存”或“提交”。
4. 编辑数据时，在对应记录右侧单击“编辑”。

“保存”或“暂存”通常只保存业务数据；“提交”或“发起流程”会将业务提交至下一办理环节。提交前应确认信息和附件完整。

### 3.4 通用删除

1. 在记录右侧单击“删除”，或勾选多条记录后单击“批量删除”。
2. 在确认窗口中核对操作。
3. 单击“确认”完成删除。

已经进入审批流程或已经办结的数据，通常不能直接删除。

### 3.5 导入和导出

导入操作：

1. 单击“导入”。
2. 下载导入模板。
3. 按模板要求填写数据，不要修改列名和表格结构。
4. 上传文件并查看导入结果。
5. 根据失败提示修正数据后重新导入。

导出操作：

1. 设置查询条件。
2. 单击“导出”。
3. 确认后下载 Excel 文件。

导出的数据通常与当前查询条件和账号数据权限一致。

### 3.6 附件操作

- 上传：单击上传区域选择文件。
- 预览：单击文件名称或“预览”。
- 下载：单击“下载”，通过浏览器保存文件。
- 删除：仅有权限且业务未锁定时可以删除附件。

提交业务前，应确认附件已经上传完成。

## 4. 流程工作台

## 4.1 发起流程

1. 进入“流程工作台”或“发起流程”。
2. 按分类查找需要发起的流程，也可以输入流程名称查询。
3. 单击流程卡片或“发起”。
4. 填写业务表单并上传附件。
5. 根据页面提示选择下一环节办理人或抄送人。
6. 单击“提交”或“发起流程”。
7. 系统提示成功后，可在“我的流程”中查看进度。

提交前应重点检查：

- 必填项是否完整。
- 日期、单位、人员和文件编号是否正确。
- 附件是否完整且可以正常打开。
- 下一环节办理人是否选择正确。

## 4.2 我的流程

“我的流程”用于查看当前用户发起的流程。

常用查询条件包括流程名称、流程分类、流程状态和发起时间。

常用操作：

- 详情：查看业务表单、流程图、审批记录和当前环节。
- 重新发起：使用原流程信息再次发起流程。部分业务表单不支持此功能。
- 取消流程：对允许取消的运行中流程填写取消原因并确认。

已取消、已结束或无权限的流程不能再次取消。

## 4.3 待办任务

“待办任务”显示当前用户需要办理的任务。

可以按办件名称、流程类型、紧急程度、来文单位、发起时间、环节时限和办结时限等条件查询。

办理步骤：

1. 进入“待办任务”。
2. 找到目标记录，单击“办理”。
3. 查看业务信息、附件、流程图和历史审批意见。
4. 填写当前环节要求的办理意见或业务字段。
5. 根据实际情况选择通过、退回、转办等操作。
6. 确认下一办理人并提交。

对于系统允许批量办结的任务，可勾选多条记录后使用批量办理功能。批量操作前必须确认所选任务业务性质和处理意见一致。

## 4.4 已办任务

“已办任务”显示当前用户已经处理的任务。

常用操作：

- 详情：查看业务内容和完整流转记录。
- 撤回：在流程条件允许时撤回刚刚完成的任务。

撤回操作：

1. 找到状态允许撤回的记录。
2. 单击“撤回”。
3. 确认撤回操作。

如果下一环节已经处理、流程已经结束或流程配置不允许撤回，系统不会显示撤回按钮或会提示不能撤回。

## 4.5 抄送任务

“抄送任务”用于查看抄送给当前用户的流程。

列表中可查看流程名称、发起人、发起时间、抄送节点、抄送人、抄送意见和抄送时间。单击“详情”可以查看完整业务内容，但通常不能进行审批。

## 4.6 综合办件查询

综合办件查询用于统一查看权限范围内的流程实例。

支持按以下条件查询：

- 办件名称、办件编号。
- 来文单位和办件类型。
- 运行状态和业务结果。
- 受理日期和超期天数。

列表可查看办件状态、当前环节、当前办理人员、紧急程度及办结时限。

## 4.7 流程详情

流程详情通常包含：

- 业务表单。
- 业务附件和审批附件。
- 当前流程状态。
- 流程图或简易流程图。
- 审批时间线和各节点办理意见。
- 当前办理人及后续环节。

部分业务详情页面提供“打印”按钮，可生成办理单并调用浏览器打印功能。

## 4.8 审批操作说明

### 通过

确认业务无误，填写审批意见，选择下一环节人员后提交。

### 驳回或不通过

业务不符合办理要求时使用。应填写明确原因。驳回后流程可能结束，具体以流程配置为准。

### 退回

将任务退回到之前的指定节点。

1. 单击“退回”。
2. 选择退回节点。
3. 填写退回理由。
4. 确认提交。

### 转办

将当前任务转给另一名人员办理。转办后，原办理人不再负责当前任务。

### 委派

将任务委派给其他人员协助处理。委派人与被委派人的后续责任以流程配置为准。

### 加签和减签

- 加签：在当前环节增加办理人员。
- 减签：移除符合条件的加签人员。

使用前应确认加签方式和人员，避免流程在当前节点等待错误人员处理。

### 抄送

将流程信息发送给相关人员查阅。抄送人员通常不参与审批。

## 5. 收文管理

### 5.1 新建收文

1. 进入“收文管理”。
2. 单击“新增”或进入“发起收文”。
3. 填写单位类别、来文单位和来文字号。
4. 获取或填写收文编号。
5. 填写收文日期、主题、紧急程度和文件类别。
6. 根据需要填写备注、主办办结时间和协办办结时间。
7. 上传来文正文及相关附件。
8. 暂存业务，或直接发起收文流程。

### 5.2 查询收文

可按标题、收文日期、办理状态、来源、收文编号、来文字号、来文单位、单位类别、文件类别和紧急程度查询。

列表支持查看详情、编辑、删除、排序和导出，具体按钮以权限和流程状态为准。

### 5.3 办理收文

1. 从“待办任务”进入收文详情。
2. 查看收文基本信息和附件。
3. 根据当前节点填写拟办意见、局长批示、领导意见或科室办理意见。
4. 上传当前节点需要的办理附件。
5. 选择下一环节和办理人员。
6. 提交任务。

### 5.4 打印收文阅办单

1. 打开收文流程详情。
2. 确认业务信息和审批意见已经加载。
3. 单击“打印”。
4. 在打印预览中检查版式。
5. 选择打印机或另存为 PDF。

未完成审批的节点在打印时可能为空。

---

## 6. 发文管理

### 6.1 新建发文

1. 进入“发文管理”。
2. 单击“新增”或进入“发起发文”。
3. 选择文件类型，如党务或政务。
4. 填写主题、发文字号、发文单位和拟稿人。
5. 填写发文日期和紧急程度。
6. 上传正文及相关附件。
7. 保存或发起发文流程。

### 6.2 查询和维护

可按主题、发文日期、办理状态、文件类型、发文字号、拟稿人、发文单位和紧急程度查询。

在权限和状态允许时，可以查看、编辑、删除或导出发文记录。

### 6.3 办理发文

从“待办任务”进入发文详情，核对正文、附件和历史意见，根据当前环节填写意见，选择下一办理人后提交。

---

## 7. 会议报告单

### 7.1 发起会议报告单

1. 进入“会议报告单”。
2. 单击“新增”。
3. 填写会议名称、会议时间和会议地点。
4. 填写召集单位及我局参会科室。
5. 填写会议相关事项并上传附件。
6. 暂存或发起审批流程。

### 7.2 查询和查看

可按会议名称、会议时间、办理状态、召集单位、会议地点和参会科室查询。

可在列表中查看详情、编辑、删除、导出或查看办理记录。

---

## 8. 请假、外出与休假备案

### 8.1 请假申请

1. 进入请假申请页面。
2. 选择请休假种类。
3. 填写开始时间和结束时间。
4. 核对系统计算的请假天数。
5. 填写请假事由并上传附件。
6. 提交审批。

请假列表支持按申请人、请假时间、请假种类、办理状态、申请时间和请假事由查询，并可在权限允许时导出。

### 8.2 外出申请

1. 进入公出或外出申请页面。
2. 填写外出开始时间和结束时间。
3. 填写出发地、目的地和外出事由。
4. 上传需要的证明材料。
5. 提交审批。

### 8.3 休假备案

休假备案用于维护和查询请休假记录。具有权限的用户可以新增、编辑、删除、批量删除和导出备案数据。

### 8.4 请假统计

系统可按条件查看请假汇总、明细、历史记录和年度统计。统计结果以已保存并纳入统计范围的数据为准。

---

## 9. 行政复议

### 9.1 案件登记

1. 进入“行政复议”。
2. 单击“新增”或“发起行政复议”。
3. 填写来文号、来文机关和收文日期。
4. 填写申请人、被申请人、第三人和土地坐落。
5. 选择案件分类、涉及事项和案件类型。
6. 填写案件请求、主要内容等信息。
7. 上传案件材料。
8. 保存或发起审批流程。

### 9.2 案件查询

可按来文号、来文机关、收文日期、申请人、第三人、案件分类、涉及事项、案件类型和办理状态查询。

### 9.3 案件办理

1. 从“待办任务”进入案件详情。
2. 核对案件基本信息和材料。
3. 根据当前节点填写拟办、领导或科室办理意见。
4. 上传当前节点意见附件。
5. 选择下一环节办理人员并提交。

### 9.4 扩展信息

案件后续可以维护：

- 复议决定日期和复议结果。
- 意见书文号、日期及内容。
- 行政赔偿金额。
- 听证日期和执行情况。
- 装订人、装订日期。
- 移交人、移交日期。

### 9.5 打印

在案件详情中单击“打印”，可打印行政复议办理单。打印前应确认审批意见、办理人员和办理日期完整。

---

## 10. 行政诉讼

### 10.1 案件登记

1. 进入“行政诉讼”。
2. 单击“新增”或“发起行政诉讼”。
3. 填写来文号、来文机关和收文日期。
4. 填写原告、被告、第三人等当事人信息。
5. 选择诉讼阶段、案件类别、案件分类、涉及事项、案件类型和诉讼类别。
6. 填写诉讼请求、诉讼内容及相关案号。
7. 上传诉讼材料。
8. 保存或发起审批。

### 10.2 案件查询

可按来文号、来文机关、收文日期、原告、被告、第三人、诉讼类型、案件分类和办理状态查询。

### 10.3 案件办理

从“待办任务”进入案件详情，根据当前节点填写拟办意见、局长意见、分管领导意见或科室办理意见，并上传相关附件后提交。

### 10.4 扩展信息

案件后续可以维护：

- 承办人和承办日期。
- 送法院机关日期和开庭日期。
- 判决结果、裁定结果及日期。
- 执行情况。
- 装订和移交信息。
- 相关文书及文书主要内容。

### 10.5 打印

打开案件详情并单击“打印”，可以打印行政诉讼审批表。

---

## 11. 会议室预约

### 11.1 查看预约日历

会议室预约页面按周展示各会议室的预约情况。

- 单击“上一周”查看前一周。
- 单击“本周”返回当前周。
- 单击“下一周”查看后一周。
- 可以切换查看“我的预约”和“他人预约”。

### 11.2 新增预约

1. 在预约日历中选择会议室和日期。
2. 过去的日期不能预约。
3. 填写预约日期、开始时间和结束时间。
4. 核对预约人、所属部门和联系方式。
5. 填写参会人数和会议主题。
6. 单击“确认预约”。

预约时间不能与已有预约冲突，参会人数应与会议室座位数匹配。

### 11.3 查看和取消预约

1. 单击日历中的预约记录。
2. 查看预约详情。
3. 对本人创建且状态允许的预约，可以修改或取消。

是否允许修改他人预约取决于账号权限。

### 11.4 月度查询和导出

1. 进入“月度查询导出”。
2. 选择需要查看的月份。
3. 单击“查询”查看月度会议室安排。
4. 单击“导出 Excel”下载月报。

### 11.5 会议室管理

管理员可以维护会议室名称、面积、座位数、备注和显示顺序，并执行新增、编辑、删除、批量删除和导出操作。

## 12. 值班管理

### 12.1 值班人员维护

1. 进入“值班管理”。
2. 单击“新增”。
3. 选择值班日期和人员类型。
4. 选择或填写值班人员。
5. 保存记录。

可按值班日期、人员类型和人员姓名查询，并查看所属部门和提醒次数。

### 12.2 批量导入

1. 单击“导入”。
2. 下载值班导入模板。
3. 按模板要求填写值班数据。
4. 上传文件并查看导入结果。

### 12.3 导出

设置查询条件后单击“导出”，可下载权限范围内的值班安排。

## 13. 节假日管理

节假日管理用于维护法定节假日、调休日和特殊工作日。

### 13.1 新增设置

1. 进入“节假日管理”。
2. 单击“新增”。
3. 选择设置日期。
4. 设置该日期是否为工作日。
5. 填写假日描述。
6. 保存。

### 13.2 批量维护

系统支持使用模板批量导入节假日数据，也可以按条件导出。修改工作日设置后，应确认相关请假天数和时限计算是否符合业务要求。

### 14.2 站内消息

通过顶部消息入口或“我的站内信”查看系统通知。未读消息应及时处理，部分流程提醒可能同时通过短信或站内信发送。

## 15. 系统管理员操作

## 15.1 用户管理

管理员可以新增、编辑、停用和删除用户，维护用户所属部门、岗位、角色、手机号和登录状态。

账号无法看到业务菜单时，应依次检查：

1. 用户是否启用。
2. 用户是否分配正确角色。
3. 角色是否拥有菜单和按钮权限。
4. 用户部门是否满足数据权限要求。

## 15.2 部门和岗位

- 部门管理：维护组织机构树、负责人和部门状态。
- 岗位管理：维护岗位名称、编码、顺序和状态。

调整部门前，应评估对流程审批人和历史数据查询的影响。

## 15.3 角色和权限

1. 新增或编辑角色。
2. 分配菜单权限和按钮权限。
3. 设置数据权限范围。
4. 将角色分配给用户。
5. 让用户重新登录以刷新权限。

不建议直接给普通用户分配系统管理、流程设计或批量删除权限。

## 15.4 菜单管理

菜单管理用于维护目录、菜单、按钮权限标识、路由地址、组件地址、图标、显示顺序和状态。

修改路由或组件地址可能导致页面无法打开，应由熟悉系统结构的管理员操作。

## 15.5 字典管理

单位类别、紧急程度、文件类别、案件分类、办理状态等下拉选项通常来自系统字典。

修改字典时应注意：

- 不随意修改已经使用的字典值。
- 停用前确认历史数据展示是否受影响。
- 新增字典项时保持标签、值和排序规则一致。

## 15.6 通知、短信和邮件

管理员可以维护通知公告、站内信模板、短信渠道、短信模板、邮件账号和邮件模板，并查看发送日志。

模板变量必须与业务调用参数保持一致，否则可能导致发送失败。

## 16. 流程管理员操作

### 16.1 流程分类和表单

流程分类用于组织发起流程页面中的流程。流程表单用于定义业务录入内容。

配置时应确认：

- 分类名称和排序。
- 表单字段、必填规则和默认值。
- 字段是否允许在各审批节点查看或编辑。

### 16.2 流程模型

创建流程模型的一般步骤：

1. 新建流程模型。
2. 填写流程名称、标识和分类。
3. 选择或设计流程表单。
4. 设计审批流程。
5. 配置审批人、抄送人和条件分支。
6. 配置节点按钮、字段权限和扩展设置。
7. 保存并发布流程。

### 16.3 审批人配置

审批人可以按用户、角色、部门、岗位、用户组或发起人自选等方式配置。发布前应确认每个节点都能解析出有效办理人。

### 16.4 流程发布前检查

- 流程标识是否唯一。
- 开始和结束节点是否完整。
- 所有审批节点是否配置办理人。
- 条件分支是否覆盖可能出现的数据。
- 退回、转办、加签和抄送是否符合业务规则。
- 表单字段权限是否正确。
- 测试账号是否可以完整走通流程。

已经投入使用的流程不宜直接大范围修改，建议创建新版本并测试后发布。

## 17. 常见状态说明

| 状态 | 说明 |
| --- | --- |
| 草稿或暂存 | 数据已保存，但尚未正式进入审批流程 |
| 办理中 | 流程正在审批，存在待办环节 |
| 审批通过 | 当前任务或整个流程已通过 |
| 审批不通过 | 流程被驳回或未通过 |
| 已退回 | 任务退回到之前的办理节点 |
| 已撤回 | 办理人撤回了已经提交的任务 |
| 已取消或已撤销 | 发起人或管理员终止了流程 |
| 已办结 | 流程所有环节已经完成 |
| 超期 | 当前日期超过环节时限或办结时限 |

实际状态名称可能因业务流程配置略有差异。

## 18. 常见问题

### 18.1 看不到某个菜单或按钮

原因通常是账号未分配相应角色或权限。退出并重新登录后仍未显示时，请联系系统管理员。

### 18.2 提交时提示没有下一环节办理人

流程节点未配置有效审批人，或当前业务条件无法匹配审批人员。记录流程名称和当前节点后联系流程管理员。

### 18.3 已上传附件但提交后看不到

确认附件是否上传完成、文件大小和格式是否符合要求。不要在上传进度结束前关闭窗口或提交表单。

### 18.4 无法撤回任务

下一环节可能已经办理，流程可能已经结束，或者当前流程未启用撤回功能。

### 18.5 无法删除业务数据

数据可能已经进入审批、已经办结，或者当前账号没有删除权限。应优先使用流程取消或业务作废方式处理。

### 18.6 导出文件没有数据

检查查询条件、日期范围和数据权限。导出结果通常只包含当前账号有权查看的数据。

### 18.7 打印内容不完整

等待详情页面加载完成后再打印，并检查审批节点是否已经产生办理意见。必要时刷新页面重新进入详情。

### 18.8 页面提示 403、404 或 500

- 403：账号没有访问权限。
- 404：菜单路由或页面地址不存在。
- 500：服务端处理异常。

出现异常时，应记录操作时间、业务编号、页面地址和错误提示，并提交给系统管理员。

## 19. 使用注意事项

1. 不要将账号和密码交由他人使用。
2. 提交审批前检查业务信息、人员、日期和附件。
3. 退回、驳回、撤回、取消和删除属于重要操作，应确认影响后执行。
4. 不要在同一业务上连续快速单击提交按钮。
5. 长时间编辑表单时，应及时暂存，避免登录失效导致内容丢失。
6. 涉及敏感业务和附件时，应遵守单位的信息安全及保密规定。
7. 操作完成后及时退出系统，尤其是在公共或共享设备上。
